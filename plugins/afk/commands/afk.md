# AFK

Enable AFK mode. Tool requests will be sent to AFKlaude for remote approval.

Execute the AFK script to toggle AFK mode on:

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/cmd_afk.py
```

The script will confirm when AFK mode is enabled. If already AFK, it will let you know.
